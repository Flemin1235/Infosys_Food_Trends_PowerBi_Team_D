<h3>Food Trends Understanding Customer Preferences</h3>  
  
This is a Power BI analytics project designed to analyze large-scale food ordering data to uncover patterns in customer behavior, menu demand, and business performance. The project integrates multiple datasets   including orders, customers, restaurants, and menu information to create a unified data model that supports interactive dashboard reporting.  
  
Through seven analytical dashboard pages, the project delivers insights into customer demographics, ordering behavior, cuisine popularity, pricing trends, loyalty indicators, and city-level operational performance. The dashboards enable stakeholders to identify high-demand food items, evaluate regional revenue contributions, understand customer segments, and make data-driven decisions related to menu optimization, pricing strategy, marketing focus, and operational planning.

<h4>Key Features</h4>  
  
Seven interactive Power BI dashboard pages  
Integrated multi-table data model (orders, customers, restaurants, menu, food)  
KPI-based performance monitoring (revenue, orders, customers)  
Customer behavior and demographic analysis  
Menu, cuisine, and pricing trend insights  
City-wise operational and revenue analysis  
Interactive filters and dynamic visual updates  

<h4>Tools and Technologies Used</h4>  
  
Power BI Desktop – Dashboard development and visualization  
DAX (Data Analysis Expressions) – Measures and calculated columns  
CSV / Excel Datasets – Data sources for analysis  
Data Modeling (Star Schema) – Relationship modeling between table
