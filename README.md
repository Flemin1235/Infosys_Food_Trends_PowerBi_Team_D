<h1>🍽️ Food Trends: Understanding Customer Preferences</h1>

<p>
This is a <b>Power BI analytics project</b> designed to analyze large-scale food ordering data to uncover patterns in 
<b>customer behavior, menu demand, and business performance</b>. The project integrates multiple datasets — including 
<b>orders, customers, restaurants, and menu information</b> — to create a unified data model that supports 
<b>interactive dashboard reporting</b>.
</p>

<p>
Through <b>seven analytical dashboard pages</b>, the project delivers insights into 
<b>customer demographics, ordering behavior, cuisine popularity, pricing trends, loyalty indicators, and city-level operational performance</b>. 
The dashboards enable stakeholders to identify <b>high-demand food items</b>, evaluate <b>regional revenue contributions</b>, 
understand <b>customer segments</b>, and make <b>data-driven decisions</b> related to menu optimization, pricing strategy, marketing focus, and operational planning.
</p>

<h2>🚀 Key Features</h2>
<ul>
  <li>📊 Seven interactive Power BI dashboard pages</li>
  <li>🧩 Integrated multi-table data model (orders, customers, restaurants, menu, food)</li>
  <li>📈 KPI-based performance monitoring (revenue, orders, customers)</li>
  <li>👥 Customer behavior and demographic analysis</li>
  <li>🍜 Menu, cuisine, and pricing trend insights</li>
  <li>🌍 City-wise operational and revenue analysis</li>
  <li>🎛️ Interactive filters and dynamic visual updates</li>
</ul>
